# Traffic Accident Risk Prediction System 

## Overview
This project utilizes a **Deep Neural Network (MLP)** to predict the probability of traffic accidents based on environmental and road geometry data. The system is deployed via a **Flask** web application.

## Features
* **Deep Learning Model:** Trained on 500k+ Kaggle records using TensorFlow/Keras.
* **Accuracy:** Achieved 87.1% R² Score.
* **Interactive Dashboard:** Web interface for real-time risk assessment.

## How to Run
1.  Clone the repository.
2.  Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```
3.  Run the application:
    ```bash
    python app.py
    ```
4.  Open browser at `http://127.0.0.1:5000`
